# AI 乱纪元

AI 时代安全大事件。

[English](README.md) | 中文

**在线页面：<https://chokebit.github.io/AISec-Timeline/>**

一份带来源的编年史，记录 AI 时代最大的损失、转折点和突破想象的时刻。每条事件都分开写清楚：损失多少、追回多少、用了 AI 的证据有多强、人在哪里。

## 收录范围

符合下面任意一条就收录：

- **金钱**：用了 AI，或有可信依据认为用了 AI，并且有公开金额或明确的影响数字。
- **转折点**：第一次，或者改变了攻防双方能力的一步，比如 AI 完成了入侵的大部分工作、大规模找到零日漏洞。凡是“首次”，都写明是谁说的、人参与到哪一步。
- **教训**：被广泛引用的未遂或无资金转出案例，并且能给出具体的启发。

AI 系统本身被攻破的事件（比如提示词注入、模型供应链攻击）暂未收录。

## AI 证据怎么分级

| `ai_evidence` | 含义 |
|---|---|
| `confirmed` | 官方、法庭文件、受害公司或 AI 的开发方明确说用了 AI，或代码分析能证明 |
| `assessed` | 警方、保险商、安全公司或知情人士认为用了 AI，但尚未坐实 |
| `self_reported` | 只有当事人提到 AI，没有细节也没有外部核实，比如 FBI IC3 的投诉、研究人员自己的报告 |
| `unknown` | 目前没有公开证据显示 AI 参与，也不能排除 |

## 金额怎么算

- 金额指转出或报告的损失。追回、冻结写在说明里，不扣减成净额。
- 年度总数不与单案相加。
- 没有人核实过的第三方估算，不当作金额。
- 保留原币金额，美元数字是约数。

## AI 参与未明的重大事件

有些事件因为量级或转折意义而收录，但目前没有公开证据显示 AI 参与，比如币安（2026 年 10 月，约 $63 亿）和 Ledger 硬件植入。调查还没结束，所以既不说是 AI 所为，也不排除。这类事件标为 `unknown`，不计入任何 AI 合计。

## 数据

所有事件都在 [`data/events.json`](data/events.json)，不打开网站也能直接用。页面上的合计都由这个文件算出。

网站分三部分，中英文各一套：

- **展馆**（首页）：沿着时间轴一次看一件，每件配一张原创图。
- **全部事件**（`/zh/events/`）：可以搜索，按类型和证据筛选。
- **事件页**（`/zh/events/<id>/`）：每件一个独立页面，方便分享，也方便搜索引擎收录。

## 本地运行

```sh
pip install playwright && python3 -m playwright install chromium   # 只需一次
python3 scripts/validate.py
python3 scripts/build.py          # 加 --no-art 跳过生成配图
python3 -m http.server 8000 -d _site
```

然后打开 <http://localhost:8000/>。源文件在 `site/`；`_site/` 是生成的，不提交。每次推送到 `main`，GitHub Actions 会自动构建并部署。`scripts/build.py` 顶部的 `SITE_URL` 决定给搜索引擎的网址，换域名时改这一行。
